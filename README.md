# CRM Ayuntamientos · versiones

Instaladores del CRM Ayuntamientos de Oficina Técnica Maestre. Aquí no hay código ni datos: solo las versiones publicadas.

- **Primera instalación:** descarga `CRM-Ayuntamientos_X.Y.Z_x64-setup.exe` de la [última versión](../../releases/latest) y ábrelo.
- **Actualizar:** dentro de la aplicación, Ajustes → Versión → «Buscar actualizaciones». Los datos se conservan.

Cada versión va firmada; la aplicación rechaza cualquier instalador que no venga de aquí.
